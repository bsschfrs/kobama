Een meta description is een korte beschrijving van een pagina die je in de code van je website zet. Google kan die tekst onder de titel van je pagina tonen in de zoekresultaten. Een goede meta description vat de pagina in een of twee zinnen samen, is voor elke pagina anders en laat de zoeker zien waarom klikken de moeite waard is.

Je leest hier wanneer Google je meta description gebruikt, hoe lang hij mag zijn en hoe je er een schrijft.

## Wat is een meta description?

Een meta description is een stukje tekst in de code van een pagina dat beschrijft waar die pagina over gaat. Bezoekers zien het niet op de pagina zelf. Het is bedoeld voor zoekmachines, die het kunnen tonen als korte tekst onder de blauwe titel in de zoekresultaten. Die korte tekst heet een snippet.

In de code ziet het er zo uit:

`<meta name="description" content="Schilderwerk binnen en buiten in Haarlem en omgeving. Vrijblijvende offerte binnen een week.">`

In de meeste websitesystemen vul je de meta description in een apart veld in, zonder dat je de code ziet.

## Gebruikt Google altijd je meta description?

Google gebruikt je meta description niet altijd. Volgens de [uitleg van Google over snippets](https://developers.google.com/search/docs/appearance/snippet) maakt Google de tekst onder een zoekresultaat vooral op basis van de inhoud van de pagina zelf. Google gebruikt de meta description soms, als die de pagina beter beschrijft dan een stuk uit de tekst.

Welke tekst Google kiest, hangt ook af van de zoekopdracht. Zoekt iemand iets heel specifieks, dan toont Google soms liever de zin uit je pagina die daar precies over gaat.

## Hoe lang mag een meta description zijn?

Een meta description heeft geen vaste maximale lengte. Google schrijft dat er geen limiet is, maar dat snippets in de zoekresultaten worden ingekort om op het scherm te passen.

Houd daarom het belangrijkste vooraan. Een of twee zinnen is meestal genoeg. Zo staat de kern er ook als Google het einde afknipt.

## Hoe schrijf je een goede meta description?

Je schrijft een goede meta description door de pagina kort en eerlijk samen te vatten, voor elke pagina opnieuw. Google geeft in zijn [uitleg over snippets](https://developers.google.com/search/docs/appearance/snippet) en de [SEO-startgids](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) deze richtlijnen:

1. **Maak hem uniek per pagina.** Dezelfde of bijna dezelfde beschrijving op elke pagina helpt niemand.
2. **Vat samen wat de pagina biedt.** Schrijf hem als een korte pitch: wat vindt de zoeker op deze pagina?
3. **Gebruik geen rij zoekwoorden.** Een lijstje woorden zegt een zoeker niet waar de pagina over gaat, en Google toont het minder snel.
4. **Noem concrete informatie.** Bij een dienstenpagina bijvoorbeeld je werkgebied, voor wie de dienst is of wat iemand kan verwachten.

| Minder goed | Beter |
|---|---|
| Schilder, schilderwerk, schildersbedrijf, Haarlem, verven | Schilderwerk binnen en buiten in Haarlem en omgeving. Je krijgt vooraf een duidelijke prijs. |
| Welkom op onze website | Loodgieter in Utrecht voor lekkages, cv-ketels en badkamers. Lees wat we doen en hoe je ons bereikt. |

## Helpt een meta description om hoger in Google te komen?

Over de invloed van de meta description op je positie in Google zegt Google in zijn uitleg over snippets niets. De meta description is vooral bedoeld om zoekers te laten zien wat ze op je pagina vinden. Een duidelijke beschrijving kan ervoor zorgen dat iemand eerder op jouw resultaat klikt.

Wat wel helpt om hoger te komen, lees je in [hoger in Google komen](/blog/hoger-in-google-komen/).

## Wat is het verschil tussen een meta description en een titel?

De titel van een pagina is de blauwe, klikbare kop in de zoekresultaten. De meta description is de korte tekst eronder. Google schrijft in zijn [SEO-startgids](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) dat een goede titel uniek is voor de pagina, duidelijk en kort, en precies beschrijft wat er op de pagina staat. Voor de meta description geldt hetzelfde, alleen heb je iets meer ruimte.

## Veelgestelde vragen

### Waarom toont Google een andere tekst dan mijn meta description?

Google toont soms een andere tekst dan je meta description omdat een stuk uit je pagina beter past bij de zoekopdracht. Google maakt snippets vooral op basis van de inhoud van de pagina. Een duidelijke, unieke meta description vergroot de kans dat Google hem gebruikt.

### Hoeveel tekens mag een meta description hebben?

Een meta description heeft volgens Google geen maximum aantal tekens. Google kort de tekst in de zoekresultaten wel in om op het scherm te passen. Zet daarom de belangrijkste informatie in het begin.

### Moet elke pagina een meta description hebben?

Elke belangrijke pagina heeft het best een eigen meta description. Ontbreekt hij, dan maakt Google zelf een snippet uit je tekst. Dat gaat vaak goed, maar met een eigen beschrijving houd je meer invloed op wat zoekers zien.

### Wat zijn meta keywords?

Meta keywords zijn een oude tag waarin je zoekwoorden voor een pagina kon zetten. Google gebruikt die tag volgens de [SEO-startgids](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) niet. Je hoeft hem dus niet in te vullen.

## Kort samengevat

Een meta description is een korte beschrijving van een pagina die Google onder je titel in de zoekresultaten kan tonen. Google gebruikt hem niet altijd. Schrijf per pagina een eigen, eerlijke samenvatting van een of twee zinnen, met het belangrijkste vooraan en zonder rij zoekwoorden.
