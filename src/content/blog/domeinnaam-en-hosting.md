Een domeinnaam is het adres van je website, zoals jouwbedrijf.nl. Hosting is de plek waar je website staat: een computer die altijd aan staat en je site aan bezoekers laat zien. Je hebt ze allebei nodig. De domeinnaam wijst bezoekers de weg, de hosting laat de website zien.

Je leest hier hoe domeinnaam en hosting samenwerken, van wie je domeinnaam is, wat het kost en waar je op let als je ze regelt.

## Wat is een domeinnaam?

Een domeinnaam is het webadres waarop mensen je website vinden, bijvoorbeeld jouwbedrijf.nl. Het deel achter de punt heet de extensie, zoals .nl of .com. Een domeinnaam registreer je per jaar, en zolang je hem verlengt blijft hij van jou.

Voor .nl-domeinnamen houdt [SIDN](https://www.sidn.nl/) het register bij. Je registreert een .nl-domeinnaam niet rechtstreeks bij SIDN, maar via een registrar: een bedrijf dat de domeinnaam namens jou aanvraagt en beheert. Dat kan je hostingbedrijf zijn, of een aparte partij.

## Wat is hosting?

Hosting is de opslag en het online zetten van je website op een server: een computer die dag en nacht aan staat en verbonden is met internet. Typt iemand je domeinnaam in, dan haalt de browser de website op bij die server.

Er zijn verschillende soorten hosting. Een eenvoudige website heeft genoeg aan een eenvoudig pakket. Een grote webshop met veel bezoekers heeft meer nodig.

## Hoe werken domeinnaam en hosting samen?

Een domeinnaam en hosting werken samen doordat de domeinnaam naar de server van je hosting verwijst. Je kunt ze bij hetzelfde bedrijf regelen, maar dat hoeft niet.

| | Domeinnaam | Hosting |
|---|---|---|
| Wat het is | Het adres van je website | De plek waar je website staat |
| Voorbeeld | jouwbedrijf.nl | Een server bij een hostingbedrijf |
| Hoe je betaalt | Per jaar, via een registrar | Per maand of per jaar, bij een hostingbedrijf |
| Kun je overstappen? | Ja, naar een andere registrar | Ja, naar een ander hostingbedrijf |

## Van wie is je domeinnaam?

Je domeinnaam is van degene die als houder geregistreerd staat. Volgens [SIDN](https://www.sidn.nl/en/faq) is de houder de eigenaar van de domeinnaam. Alleen de houder kan de domeinnaam overdragen aan iemand anders.

Let hierop als je webbouwer je domeinnaam voor je registreert. Staat de webbouwer als houder geregistreerd, dan is de domeinnaam formeel niet van jou. SIDN raadt aan om in dat geval de houder te laten wijzigen naar je eigen naam of bedrijf. In de Whois van SIDN zie je op wiens naam een .nl-domeinnaam staat, als de houder een bedrijf is.

## Wat kost een domeinnaam?

Wat een .nl-domeinnaam kost, bepaalt de registrar. SIDN schrijft registrars niet voor welke prijs ze vragen, dat staat op de [pagina van SIDN over registreren](https://www.sidn.nl/en/nl-domain-name/registering-a-domain-name). Vergelijk daarom een paar registrars, en kijk ook naar de prijs voor verlengen. Die kan anders zijn dan de prijs in het eerste jaar.

## Hoe stap je over naar een andere registrar of host?

Je stapt met een .nl-domeinnaam over naar een andere registrar met een verhuistoken: een unieke code van je domeinnaam. Je huidige registrar moet je die volgens SIDN binnen vijf dagen geven als je erom vraagt. Die code geef je aan je nieuwe registrar.

Overstappen naar een andere hosting betekent dat je website naar een nieuwe server gaat, en dat je domeinnaam daarna naar die nieuwe server moet verwijzen. Regel dat op een rustig moment, zodat je site zo kort mogelijk onbereikbaar is.

## Wat gebeurt er als je je domeinnaam niet verlengt?

Als je je domeinnaam niet verlengt, kan de registrar hem opzeggen. Een .nl-domeinnaam die is opgezegd, gaat volgens SIDN eerst in quarantaine. In die periode kan de oude houder hem via een registrar terugkrijgen. Daarna komt de domeinnaam vrij en kan iemand anders hem registreren.

Zet daarom automatisch verlengen aan, en zorg dat het e-mailadres bij je registrar klopt. Dan mis je geen herinnering.

## Veelgestelde vragen

### Kan ik een domeinnaam hebben zonder hosting?

Je kunt een domeinnaam hebben zonder hosting. Je registreert hem dan alleen, bijvoorbeeld om de naam vast te leggen. Er staat pas een website op het adres als je ook hosting regelt en de domeinnaam naar die hosting laat verwijzen.

### Moet ik mijn domeinnaam en hosting bij hetzelfde bedrijf regelen?

Je hoeft je domeinnaam en hosting niet bij hetzelfde bedrijf te regelen. Bij één bedrijf is het overzichtelijk. Bij twee bedrijven kun je makkelijker van hosting wisselen zonder aan je domeinnaam te komen.

### Wat is het verschil tussen een domeinnaam en een website?

Een domeinnaam is alleen het adres, de website is wat je op dat adres ziet. Een domeinnaam zonder website is een adres zonder huis. Een website zonder domeinnaam is alleen bereikbaar via een technisch adres dat niemand onthoudt.

### Hoe zie ik van wie een .nl-domeinnaam is?

Je ziet van wie een .nl-domeinnaam is via de Whois op de website van SIDN. De naam van de houder is daar alleen zichtbaar als de houder een bedrijf is. Bij particulieren blijft de naam verborgen.

## Kort samengevat

Een domeinnaam is het adres van je website, hosting is de plek waar hij staat. Je registreert een .nl-domeinnaam via een registrar en verlengt hem elk jaar. Zorg dat de domeinnaam op jouw naam staat, zet automatisch verlengen aan, en kies hosting die past bij hoe groot je site is.
